# İl sayfaları — kaynaklar

İçerik: `src/content/data/city-pages/<il>.json`. İçe aktarma: `npx tsx --conditions react-server scripts/seed-city-pages.ts --publish` (parametresiz kuru çalışır). Kontrol: `node scripts/check-district-pages.mjs src/content/data/city-pages`.

Yalnızca Vikipedi veya haber kaynağına dayanan ifadeler (ör. Antalya, Kocaeli teknopark satırı, Gaziantep halı ihracatı, Eskişehir seramik kümesi) müşteri tarafından gözden geçirilmelidir.
